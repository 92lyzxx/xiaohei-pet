## 使用说明

### Windows

1. 在 Releases 页面下载 `xiaohei-pet-setup.exe`。
2. 双击运行安装程序，按提示完成安装。
3. 从开始菜单或桌面快捷方式启动桌宠。

### macOS

1. 在 Releases 页面下载 `xiaohei-pet-mac.dmg`。
2. 打开 dmg，将应用拖入「应用程序」文件夹。
3. 首次打开若提示无法验证开发者，请在「系统设置 → 隐私与安全性」中允许打开。

## 校验安装包完整性

下载完成后，可对照上表的 SHA-256 值校验文件是否完整、未被篡改：

- Windows（PowerShell）：`Get-FileHash .\xiaohei-pet-setup.exe -Algorithm SHA256`
- macOS：`shasum -a 256 xiaohei-pet-mac.dmg`
